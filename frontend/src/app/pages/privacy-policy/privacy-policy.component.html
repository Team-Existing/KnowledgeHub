Data Privacy & What Leaves Your Device

Knowledge Hubs is local-first. There are no cloud AI providers: extraction, embeddings and answers are all computed on the machine running the backend.

🟢 Local Processing

All AI processing uses sentence-transformers for embeddings and Ollama for LLM inference, both running locally.

  • Embeddings are computed locally — no vectors are sent to an AI service
  • GraphRAG queries, extraction, and summarisation all run on-device
  • The provider badge shows 🟢 Local on every AI-powered screen
✓ No content is sent to any AI provider.

🌐 Outbound Connections

  • ArcadeDB — all your data goes wherever ARCADEDB_URL points. With ArcadeDB on this machine nothing leaves it; with a remote server, everything you ingest (including embeddings) is stored there
  • URL ingestion — the server fetches the page you enter (private and loopback addresses are blocked)
  • Model downloads — pulled from the Ollama registry when you install a model

🗄 What Is Stored Locally

  • ArcadeDB — the only data store: accounts, artifacts, knowledge items and the links between them, embeddings, search indexes and query logs
  • Browser localStorage — your JWT auth token only
  • sessionStorage — GraphRAG chat history (cleared when the tab closes)

🔑 Authentication

  • Passwords are hashed with bcrypt — never stored in plaintext
  • JWT tokens expire after 8 hours; the server rejects expired tokens and the app then signs you out
  • Tokens are stored in localStorage and cleared on logout or expiry

📦 Model Downloads

  • Models are pulled from the Ollama registry — only the model binary is downloaded
  • No user content is sent during model download
  • Models are stored on your machine and run entirely offline after download

🛡 Your Rights

  • You own all data you ingest — delete any artifact or item at any time via the UI or API
  • Full workspace export is available via GET /knowledge/okf/export
  • No analytics, telemetry, or third-party tracking are included in this application
