Connect a Slack workspace
  1. At api.slack.com/apps, create an app (from scratch) in your workspace.
  2. Copy its Signing Secret (Basic Information) and add it below.
  3. Under Slash Commands, create /decisions with the request URL shown after adding, and a short description.
  4. Install the app to the workspace.
